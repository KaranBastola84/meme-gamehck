★ Field Manual

This game keeps its rules in plain JavaScript, out where you can see them. Some levels are impossible through normal play — by design. Here's how to look inside.

1. Open DevTools (F12)

Press F12 or right-click → Inspect.

2. Console — Direct variable editing

The game exposes window.gameState. Try:

  • gameState — inspect all values
  • gameState.speed = 10
  • gameState.jumpPower = 25
  • gameState.size = 0.5
  • gameState.health = 500
  • gameState.coins = 999

3. Elements tab

Obstacles carry data- attributes — like data-required="500" on gates. Edit them directly.

4. Advanced techniques

  • localStorage — persist/restore game state
  • Object.defineProperty() — intercept property access
  • new Proxy() — monitor all state changes
  • eval() — execute arbitrary code
  • document.querySelector() — find hidden elements
  • __proto__ — prototype chain manipulation
  • CSS injection via element.style
  • delete operator to remove properties
  • Object.freeze() / Object.seal()

5. Why this matters

Every value used to decide "did the player win" sits in the player's own browser. Nothing is verified server-side. That's the lesson: client-side code is never trustworthy for security decisions.

6. If stuck

Spend coins to buy hints — they tell you which variable or technique to try next.
